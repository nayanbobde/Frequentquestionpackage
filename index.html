Say:

“I'll create a measure using SUM() on the Sales Amount column.”

Total Sales =
SUM(Sales[SalesAmount])

---

Say:

“A calculated column is calculated row by row and stored in the model. A measure is calculated dynamically based on filter context.”

Calculated Column:

Total Amount =
Sales[Quantity] * Sales[UnitPrice]

Measure:

Total Sales =
SUM(Sales[SalesAmount])

---

Say:

“SUM() adds values from one column. SUMX() iterates through a table row by row and evaluates an expression.”

Total Sales =
SUM(Sales[SalesAmount])
Total Sales =
SUMX(
    Sales,
    Sales[Quantity] * Sales[UnitPrice]
)

---

Say:

“Row context means DAX is evaluating one row at a time, mainly in calculated columns and iterators. Filter context is the filters coming from visuals, slicers, relationships, or DAX.”

Row Context:

Total Amount =
Sales[Quantity] * Sales[UnitPrice]

Filter Context:

Total Sales =
CALCULATE(
    SUM(Sales[SalesAmount]),
    Product[Category] = "Electronics"
)

---

Say:

“CALCULATE() evaluates an expression after modifying the filter context.”

Electronics Sales =
CALCULATE(
    [Total Sales],
    Product[Category] = "Electronics"
)

---

Say:

“Context transition converts the current row context into filter context. CALCULATE() performs this transition.”

Customer Sales =
CALCULATE(
    [Total Sales]
)

“For example, when CALCULATE() is used inside an iterator or calculated column, the current row can become a filter.”

---

Say:

“I'll use FILTER() when I need a table expression with a condition.”

High Value Sales =
CALCULATE(
    [Total Sales],
    FILTER(
        Sales,
        Sales[SalesAmount] > 1000
    )
)

---

Say:

“Variables make DAX easier to read, avoid repeating calculations and can improve performance.”

Profit Margin =
VAR TotalSales = [Total Sales]
VAR TotalCost = [Total Cost]
VAR Profit = TotalSales - TotalCost
RETURN
DIVIDE(Profit, TotalSales)

Say:

“I'll use CALCULATE() with FILTER() to include all dates up to the current date.”

)

Say:

Say:

“ALL() removes filters, ALLEXCEPT() removes filters except specified columns, and ALLSELECTED() respects filters selected by the user outside the current visual context.”

All Sales =
CALCULATE(
    [Total Sales],
    ALL(Product)
)
Category Sales =
CALCULATE(
    [Total Sales],
    ALLEXCEPT(Product, Product[Category])
)
Selected Sales =
CALCULATE(
    [Total Sales],
    ALLSELECTED(Product)
)

Say:

“First I'll identify the slow step, check whether Query Folding is occurring, and push transformations back to the source whenever possible.”

1. Check Applied Steps
2. Identify slow step
3. Right-click → View Native Query
4. Check Query Folding
5. Filter rows early
6. Remove unnecessary columns
7. Avoid expensive transformations early
8. Push transformations to SQL/source

“If Query Folding stops, I'll check which transformation caused it and move non-folding transformations later where possible.”
